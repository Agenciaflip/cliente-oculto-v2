# 🎨 Frontend - Cliente Oculto v2.0

> Interface visual do sistema de cliente oculto

## 📋 Status

🚧 **Em desenvolvimento** - Estrutura será criada em breve

## 🛠️ Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase Client
- React Router v6

## 📁 Estrutura Planejada

```
frontend/
├── src/
│   ├── pages/           # Páginas (rotas)
│   ├── components/      # Componentes reutilizáveis
│   ├── lib/             # Utilitários
│   ├── hooks/           # Custom hooks
│   └── integrations/    # Supabase client
├── public/              # Assets estáticos
├── .env.example         # Exemplo de variáveis
└── package.json         # Dependências
```

## 🚀 Como Rodar (quando implementado)

```bash
npm install
npm run dev  # http://localhost:5173
```
